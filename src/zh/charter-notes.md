《[共道宪章](/zh/charter/)》把**人权**与**共生**定为所有参与者的基础。宪章正文力求简短；这份文件用来解释这两项原则、给出案例，并列出还需要大家共同讨论的问题。这里的内容讨论成熟后，可以经修订程序写入宪章。

## 一、为什么先定义这两条

人权回答的是“**哪些事情不能对人做**”；共生回答的是“**我们应当怎样与他人共同生活和发展**”。前者是底线，后者是方向。

- 只有底线，没有方向：社会可能只是互不侵犯，却彼此冷漠。
- 只有方向，没有底线：就可能有人以集体利益、宗教使命或发展目标为理由，强迫和牺牲个人。

所以宪章规定：**人权优先**。任何以共生为名的做法，都不能以侵犯个人的基本权利为代价。

## 二、平台“执行底线，倡导方向”是什么意思

宪章里的原则有两种：

| | 人权（底线） | 共生（方向） |
|---|---|---|
| 性质 | 不能做的事 | 值得追求的事 |
| 平台怎么对待 | 越过底线的行为会被处理 | 只倡导，不考核 |
| AI 审核查什么 | 是否违反 | 只查其中的底线部分：是否号召消灭、迫害、强迫他人 |

一篇文章不必歌颂人权与共生，也不必写得“积极向上”。只要没有越过底线，就可以发表。这样做，是为了不让“共生”变成另一种观点审查。

## 三、案例对照

| 情形 | 依据 | 判断 |
|---|---|---|
| 某个道场要求成员不能退出，退出就受威胁 | 第五条 独立自主，进出自由 | 违反 |
| 某个成员离开原来的道场，另立自己的道场 | 第五条 | 正当，应当尊重 |
| 文章号召攻击、迫害不同信仰的人 | 第四条 尊重生命，人格平等 | 违反 |
| 文章严厉批评另一个道场或宗教的观点 | 第七条、第十一条 | 观点争论，保留 |
| 文章支持或反对某国政府的政策 | 第十二条 | 观点，保留 |
| 文章公开某位匿名作者的真实身份 | 第十四条、第十七条 | 违反 |
| 一家公司靠欺骗、造谣打垮竞争对手 | 第六条 正当竞争 | 违反共生 |
| 一家公司服务更好，抢走了其他公司的客户 | 第六条 | 正当竞争，不违反 |
| 某个群体想发展自己，却号召消灭另一个群体 | 第六条、第十四条 | 越过底线 |
| 企业为了利润严重污染公共环境 | 第八条 共同责任 | 不符合共生方向 |
| 一个富裕的群体帮助弱势儿童 | 第四条、第八条 | 共生精神的实践 |

（平台只处理**发生在本平台上**的内容与行为。上表中平台以外的情形，是为了说明原则本身怎样理解，平台并不对它们作出处理。）

## 四、一个例子：两种发展方式

以开公司为例。

**零和对抗的想法**：对手做得比我好，我就想办法打击他、破坏他的生意，甚至希望他消失。

**共生发展的想法**：对手做得比我好，我先研究差距。我能提升，就改进服务；我的长处在别处，就调整方向；对方更适合经营这项业务，也可以通过公平交易转让，或者与他合作。

共生不是放弃竞争，而是**把竞争放在公平的规则之内**，把合作和资源的自由流动当作更好的选择。公平竞争中有人失去客户，不是伤害；用欺骗、暴力、恶意破坏取得优势，才是不正当的伤害。

道场之间也是一样：一个道场的文章更受欢迎，别的道场可以学习、改进，或者走自己的路；但不应造谣、冒充、打压对方。

这个道理同样适用于夫妻、家庭、组织、宗教、族群和国家之间。各种关系的法律责任和具体规则并不相同，但**尊重独立、不强迫、不以伤害谋发展、允许自由退出**，这几条可以贯穿其中。

## 五、关于“人权”的参考

宪章的人权部分主要参考联合国《世界人权宣言》（1948）。它不是从某一种宗教或哲学出发，而是从人的尊严、平等和基本自由出发：

- 第一条：人人生而自由，在尊严和权利上一律平等；
- 第二条：不因种族、肤色、性别、语言、宗教、政治或其他见解、出身等而受歧视；
- 第三条：生命、自由和人身安全；
- 第十二条：隐私不受任意干涉；
- 第十八至二十条：思想、良心和宗教自由，表达自由，和平集会和结社自由；
- 第二十九条：人在共同体中享有权利，也对共同体负有义务。

需要说明两点：《世界人权宣言》是国际社会公认的重要人权标准，但它本身不是对各国直接具有条约约束力的国际条约；《共道宪章》也不是法律，它是参与者自愿接受的共同底线。

## 六、待讨论的问题

欢迎各参与方就下面的问题提出意见（邮件 [join@dao10.org](mailto:join@dao10.org)，或投稿发表你的看法）：

1. **人权清单要不要扩展**？宪章目前列出的是人身与思想方面的基本自由。受教育、劳动、健康等经济社会方面的权利，是否也要写入？写入后平台又如何避免把它们变成观点审查？
2. **“共生的底线”要不要更具体**？目前只列出“号召消灭、驱逐、迫害、奴役群体”和“强迫他人加入或留在团体”。还有哪些行为应当算作越过共生的底线？
3. **对自然的责任怎么表述**？宪章把它放在“方向”里，不作为审核依据，以免争论环保政策的文章被误拦。这样是否合适？
4. **“乐见发展”能否有看得见的做法**？例如各道场互相推荐好文章、互设链接。这些做法是否需要写进规则？
5. **修订程序怎么定**？由各道场共同表决，还是其他办法？门槛如何设定，才能既防止被少数人操纵，又不至于无法修改？
