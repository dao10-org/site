共道文明是非营利的平台。**非营利不是不能有收入，而是收入只能用于平台本身，不分给任何个人**。平台不需要很多钱；正因为钱少，才更要每一笔都看得见。

本页说明钱从哪里来、花到哪里去、怎样公开、怎样对账。每一笔实际账目见〔[公开账目](/zh/ledger/)〕。

## 一、三条基本原则

1. **够用就好**：平台只做“存、展、通”，开销很小，不追求多收钱。
2. **只为平台本身**：所有收入只用于本平台的运转和建设，不为平台以外的任何事项募捐。
3. **每一笔都公开**：收入、支出、更正、对账全部公开，任何人都可以查、可以下载、可以核对。

## 二、收入从哪里来

| 来源 | 说明 |
|---|---|
| 发起团队自愿承担 | 目前全部开销由发起团队承担。这不是会费，也不要求每个成员出钱；谁出了多少，同样记账公开 |
| 小额捐赠 | 只用于本平台；不附带任何条件；可以指定捐给某个专项，也可以不指定 |
| 出版者自愿回馈 | 文章按 CC 授权可以免费出版印刷，平台不收版权费；出版者愿意回馈的，欣然接受 |

**不收的钱**：会费、广告费、商业服务费、版权费、付费推荐或付费置顶；以及任何附带条件的钱——比如“捐给你们，但要推荐某篇文章”或“删掉某篇文章”。

**来自中国大陆的捐赠**不禁止，但可能留下资金记录，请捐赠人自行考虑。

捐赠人姓名**默认不公开**，账目上显示为“匿名”；本人同意时才公开署名。

## 三、开支分两部分

和通行的非营利组织一样，开支分成**行政总费用**和**专项费用**两本账，分开记、分开公开。

### 1. 行政总费用（通用基金）

维持平台日常运转的长期费用，例如：

- 域名、网站托管、镜像；
- AI 审核的接口费用；
- 邮箱等基础服务；
- 组织注册、年审、法律咨询；
- 收款和转账的手续费。

**未指定用途的收入，全部进入通用基金。**

### 2. 专项费用

平台自身的一项具体建设，单独立项、单独记账，例如：把一批文章译成英文、印刷离线合集、架设一台镜像服务器、上线交流论坛。

每个专项在立项时公开以下内容：

| 项目 | 说明 |
|---|---|
| 名称与目的 | 做什么，为什么做 |
| 预算（目标金额） | 需要多少钱 |
| 起止时间 | 计划什么时候完成 |
| 行政费声明 | 专项里有没有一部分钱用于行政开销，比例多少。**默认零行政费** |
| 状态 | 进行中 → 对账中 → 已完结 |

专项的规则只有四条：

1. **专款专用**：指定给某个专项的捐赠，只能用于这个专项。
2. **结余归零才算完结**：专项结束时，账面结余必须归零。剩下的钱公开调入通用基金，并在账目中记一笔“调拨”。
3. **做不成也要交代**：专项因故无法完成时，公开说明原因，结余同样公开调入通用基金。
4. **只限平台自身**：专项只能是本平台自己的建设，不为任何道场的线下事务、救助或其他平台以外的事项设立（见《[共道宪章](/zh/charter/)》第三条）。

## 四、每一笔怎样记

每一笔收入或支出都有一个**编号**（如 `GD-2026-0001`），并记录：

| 字段 | 说明 |
|---|---|
| 编号、日期 | 编号按顺序发放，不重复使用 |
| 类型 | 收入、支出，或基金之间的调拨 |
| 基金 / 专项 | 记在通用基金，还是某个专项 |
| 类别 | 如“域名”“翻译费”“捐赠（指定专项）” |
| 金额 | 统一折算成美元；同时写明原币金额（欧元、格里夫纳、数字货币等） |
| 对方 | 付款给谁、从谁那里收到；捐赠人默认“匿名” |
| 交易尾号 | 银行流水号或链上交易哈希的末几位，方便捐赠人自己核对 |
| 凭证 | 发票或收据的链接（会先隐去个人信息） |

**捐赠人怎样查自己的捐赠**：收到捐赠后，记账人会告诉你这笔捐赠的编号（如果你留了联系方式）。你也可以在〔公开账目〕页面输入编号或交易尾号直接查找，不需要登录。

## 五、记错了怎么办：只追加，不删除

1. **已公开的记录永远不删除、不修改。**
2. 记错了，就把原记录标为“作废”，**划线保留、公开理由**，不再计入合计；再追加一条正确的记录。
3. 账目原始数据存放在公开的代码仓库里，每一次改动都有时间和记录，任何人都可以在 [GitHub](https://github.com/dao10-org/site/commits/main/src/_data/finance.json) 上查看全部修改历史。
4. 每次更新网站，账目都会生成可下载的表格文件，并附 SHA-256 校验码（见〔[离线下载](/zh/download/)〕），任何人都可以保存一份，日后对照，防止账目被悄悄改动。

## 六、对账

- **每月对账一次**：把账面结余和实际账户余额（银行账户、数字货币地址等）逐一核对，结果公开在〔公开账目〕页面，有差额必须写明原因。
- **专项结项时单独对账**：结余归零、调拨记录齐全后，状态才改为“已完结”。
- **每年发布一份年度收支报告**，一页纸即可：一年收了多少、花了多少、每个专项做成了什么。
- 组织正式注册后，按乌克兰法律向主管部门报告财务；如果收入规模变大，再考虑请外部审计。

## 七、谁来记账

- 由发起团队指定一名**记账人**，另一名成员**复核**。每笔账至少两个人看过，才公开。
- 记账人和复核人只公开职责，不必公开真实姓名。
- 记账人不能给自己报销而不经复核；任何成员垫付的钱，同样作为一笔公开记录。

## 八、现在的状态

- 平台运营主体计划注册为乌克兰非营利民间组织（громадська організація），**收款渠道尚未开通**。组织注册完成后，会在本页公布正式的收款方式（可能包括银行账户和数字货币地址），**除本页公布的方式以外，任何以“共道文明”名义的收款都不是我们**。
- 目前全部开销由发起团队直接支付，并已记入公开账目。
- 本制度为草案，组织注册时由律师审定；之后的每一次修改都会公开记录。

## 九、给各道场和团体的建议

本制度只管共道文明平台自己的钱。各道场、各团体如果为某件事筹集经费，平台推荐（不强制）参考同样的思路，详见三篇文章和一份记账表格：

- 《[账目清楚，道义才立得住](/zh/library/clear-accounts/)》
- 《[一套简单的记账方法](/zh/library/simple-bookkeeping/)》（附[记账模板](/assets/files/shixiang-jizhang-moban.xlsx)）
- 《[公开什么，向谁公开，怎样保护隐私](/zh/library/disclosure-and-privacy/)》

各道场的收款和捐款是道场自己的事务，共道文明不代收、不经手、不担保、不监督，也不为其承担经济责任。
